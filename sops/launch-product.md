# SOP: Produktlansering

Följ dessa steg i ordning. Anropa rätt agent i varje steg. Stanna för användarens granskning vid markerade punkter.

1. **Research** (product-manager) → skapa/uppdatera products/[produkt].md
2. **Positionering** → sammanfatta USP och prisförslag → GRANSKNING AV ANVÄNDAREN
3. **Copy** (copywriter) → produkttext enligt skills/write-product-copy.md
4. **Kreativ riktning** (creative-director / meta-ads) → annonsvinklar + creative-brief
5. **Shopify-sida** (shopify-dev) → bygg sektion/template, följ skills/cro.md
   - Visa diff, pusha ENDAST till Dev-temat (199813333317) efter bekräftelse
6. **Annonser** (meta-ads) → 3 vinklar att testa
7. **SLUTGRANSKNING AV ANVÄNDAREN** innan något publiceras eller går live
