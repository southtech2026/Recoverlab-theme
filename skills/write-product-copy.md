# Skill: Skriv produkttext

## Struktur (i ordning)
1. **Problem** — vilket problem känner kunden igen?
2. **Lösning** — hur löser produkten det?
3. **Fördelar** — konkreta, inte svulstiga
4. **Trygghet (trust)** — recensioner, garanti, frakt, betalning
5. **CTA** — tydlig uppmaning

## Regler
- Svenska, alltid
- Ingen hype, inga medicinska löften, inga garanterade resultat
- Premium ton, kort och skarp
- Skriv för konvertering, inte för att imponera med ord
